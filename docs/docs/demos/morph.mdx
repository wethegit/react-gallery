# Morph Gallery

Morph gallery using a smooth, eased WebGL image morphing transition.

Under the hood, it cross-blends and warps between two images on a full-bleed canvas using custom shaders, quintic easing (easeInOutQuint), aspect-ratio scaling, and directional movement.
