# Custom controls with useGallery

For anything the built-in nav and pagination components don't cover, the [`useGallery`](/docs/api/use-gallery) hook exposes the gallery state and navigation methods. This demo builds its own arrows, a counter, and jump-to-slide buttons, and logs every `onChange` event fired by the `<Gallery>` provider.

## Notes

- `useGallery` must be called from a component **inside** `<Gallery>`; calling it outside the provider throws. That is why `Controls` is a separate component.
- `next`, `previous`, and `goToIndex` all trigger the `onChange` callback; `setActiveIndex` (also returned by the hook) changes the index silently without firing it.
- The event log shows `direction` as `1` for forward moves and `0` for backward moves, including wraps when `loop` is set.
- `styles.*` comes from the demos' shared SCSS module; see the [basic gallery demo](/docs/demos/basic#styles) for the relevant excerpt.
